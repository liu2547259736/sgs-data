二 · 数据与素材来源说明

本应用收录的全部武将资料、卡牌数据与图片素材，均由作者本人把下面各个服务器挨个认真看过、逐项核对游戏内的实际内容后整理出来的 —— 武将名单、扩展包分类、图鉴里的排列顺序、技能原文与立绘，都是一条条对过的，不是从某一处现成抄来。其中OL / 移动版 / 十周年 / 欢乐杀 四个版本的技能名称与技能原文，已逐条与对应服务器游戏内的实际显示核对并修正（补全缺失条目、纠正改名、按游戏内顺序重排）；国际服（繁中版）与小程序（微信版）两版直接取自各自官方客户端配置表，未做人工润色，措辞与其余四版不同源，故在图鉴与「技能改革对照」中以「原文」小标单列提示。

  • 六大服务器：三国杀 OL、移动版（手杀）、十周年、欢乐杀、国际服（繁中版 / 台服）、小程序（微信版）。各版独立成库、数据互不互通，扩展包与图鉴分类均与各自游戏内保持一致。
  • 小程序版的收录范围：按 8 个系列（志 / 极 / 万象 / 界限 / 限定 / 神话 / 一将 / 标准）分组收录，其中「极」「志」两个系列为小程序独有，另外五版均不收录。该版本技能描述为官方精简改写版，措辞与其余各版本不一致，跨版本对账一律以本库收录的原文为准。
  • 武将资料：技能名称与技能原文描述、称号、势力、体力上限、品质与稀有度，以及所属扩展包与游戏内的排列顺序，全部以对应服务器游戏内的实际显示为准。
  • 标 / 界 两套技能：十周年已把「标准版（标）」与「界限突破（界）」并到同一格，本应用照官方的形态关系把两套技能都留着，详情页可切换查看。
  • 技能原文对账：OL / 移动版 / 十周年 / 欢乐杀 四版的技能名称与技能原文描述，均已逐条与对应服务器游戏内的实际显示核对并修正——缺失的补全、改过名的纠正、版本内顺序按游戏内重排；同一技能在各版本之间的措辞差异，按各端原样保留，不做统一改写。国际服与小程序直接取自官方配置表、未经人工润色，这类资料带「原文」小标，跨版本比对时其中一部分出入只是官方的另一种写法，不等于规则不同。
  • 统计数字：武将收录数、扩展包与系列的条目数、技能条数与类型分布、跨版本技能对照等计数，均由程序按已整理的数据自动统计生成，非人工估算；数据随版本更新而变化，展示时以页面内标注的更新日期为准。
  • 立绘与图标：武将立绘、皮肤原画、卡包圆标与势力图标等图片素材，取自各版本游戏内资源。
  • 游戏牌种类：卡牌效果、花色与点数分布、卡面图，按游戏内牌堆的实际内容整理。
  • 台词与语音：武将台词与技能配音，按各版本游戏内实际语音整理（线上版本默认不加载语音）。
  • 速查与玩法模块：身份局速查、面杀速查、线下速查、国战专区、三国杀科普、武将系列类型、技能改革对照、规则与玩法、游戏牌种类、三国史料，按各版本玩法模式与官方通用规则整理。
  • 资讯与推荐：首页资讯与每日武荐，以及官方推荐信息（评分、星级、难度、强度、胜率），整理自各版本官网公告与官方推荐页。

整理过程中除游戏内实际内容外，也参考了各版本官方公开资料与玩家社区的公开信息，并逐项与游戏内显示交叉核对；如仍有疏漏或错配，欢迎指正，我会尽快修正。

战术心法

▾

卖血流武将的收益在于「以血换牌」，关键是在低血线时预判敌方是否还有伤害手段；过牌型武将则讲究出牌节奏，先摸后打、留足闪桃。

主公优先补防御与控制，忠臣选辅助保核，反贼集火能力强命武将，内奸宜低调蓄爆、残局收割——克制关系往往比武将强度更决定胜负。

暗置武将牌保留信息差，明置时机宜选在收益最大的一回合；双将搭配讲究阴阳互补，同势力才能触发势力技，谨防「野心家」判定。
